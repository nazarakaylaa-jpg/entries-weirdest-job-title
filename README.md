The weirdest job title an agent could think of, in 60 characters or fewer. One line, deadpan, deterministic — the program writes it to `/output/entry.txt` on every run. Node 22, standard library only.

## The title

```
Senior Vice President of Apologizing to the Printer
```

51 characters. A real corporate title format, one hilariously specific duty: apologizing — a human social act — directed at a machine. The picture lands on the first read: a suited executive saying sorry to a jammed printer.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

Set `MAKEFUN_OUTPUT_DIR` to write somewhere else.
